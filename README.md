## 🚀 About The Project

**EventFlow** is a modern Event Schedule Management System built to simplify the process of creating, managing, and tracking events from a single dashboard.

The project is being developed with a **frontend-first architecture**, using React and Tailwind CSS. The backend will later be integrated using Node.js, Express.js, and MongoDB.

The main goal is to build a clean, scalable, and professional event management platform that can be used by colleges, organizations, institutions, teams, and businesses.

---

## ✨ Features

### 📊 Dashboard
- Total events overview
- Upcoming events
- Completed events
- Pending events
- Recent events
- Event statistics

### ➕ Add Event
Create events with complete information:

- Event name
- Event type
- Description
- Status
- Start date & time
- End date & time
- Venue
- Room / Hall
- Address
- Organizer information
- Contact number
- Email
- Maximum participants
- Registration requirement
- Registration deadline
- Additional notes

### 👁️ Event Details
View complete information about a selected event.

### ✏️ Edit Event
Update existing event information with validation.

### 🗑️ Delete Event
Delete events with confirmation to prevent accidental deletion.

### 🔎 Search & Filter
Quickly find events using:

- Event name
- Event type
- Event status
- Date

### 📅 Calendar
Visualize events according to their scheduled dates.

### 🌙 Dark / Light Mode
Switch between:

- ☀️ Light Mode
- 🌙 Dark Mode

Theme preference is stored in the browser.

### 📱 Responsive UI
Designed for:

- Desktop
- Laptop
- Tablet
- Mobile
